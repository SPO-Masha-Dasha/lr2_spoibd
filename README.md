# Доска объявлений на Django

Учебный проект по книге "Django 4: Практика создания веб-сайтов на Python".

## Функционал
- Вывод объявлений
- Рубрики (категории)
- Админ-панель
- Форма добавления объявлений
- Статические файлы (CSS)

## Установка
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Применить миграции: `python manage.py migrate`
4. Создать суперпользователя: `python manage.py createsuperuser`
5. Запустить сервер: `python manage.py runserver`

## Структура проекта
- `bboard/` - приложение доски объявлений
- `samplesite/` - настройки проекта
- `static/` - CSS и изображения
- `templates/` - HTML шаблоны
